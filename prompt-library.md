# Prompt Library for AI Coding Assistants (Frontend Development)

## Introduction

This prompt library contains three simple prompts for frontend development tasks: code generation, debugging, and refactoring.

---

## 1. Code Generation Prompt

### Prompt

Create a responsive React Task Manager using React.js and Tailwind CSS.

Features:

* Add tasks
* Edit tasks
* Delete tasks
* Mark tasks as completed
* Display task title, description, and due date

Use React Hooks and reusable components.

### Result

**AI Assistant:** ChatGPT

### Outcome

* Generated React components
* Used React Hooks for state management
* Added responsive Tailwind CSS styling
* Implemented CRUD functionality

### Evaluation

* Functional implementation
* Responsive design
* Reusable component structure

---

## 2. Debugging Prompt

### Prompt

Analyze the following React code, identify the issue, explain it, and provide the corrected version.

### Result

**AI Assistant:** ChatGPT

### Outcome

The AI identified that the event handler was executed during rendering instead of when the button was clicked.

### Evaluation

* Correctly identified the problem
* Provided a working solution
* Explained the cause clearly

---

## 3. Refactoring Prompt

### Prompt

Refactor the React code to improve:

* Readability
* Maintainability
* Component structure
* React best practices

Explain all changes made.

### Result

**AI Assistant:** ChatGPT

### Outcome

* Improved code readability
* Removed unnecessary code
* Used better React practices
* Simplified component structure

### Evaluation

* Cleaner code
* Easier maintenance
* Better React standards

---

## Conclusion

AI coding assistants can help frontend developers by generating code, debugging issues, and refactoring applications. Well-written prompts lead to more efficient and maintainable solutions.
