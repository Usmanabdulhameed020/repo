# SDLC Review Questions

## 1. What is SDLC?
SDLC (Software Development Life Cycle) is a process used to plan, design, develop, test, deploy, and maintain software systems.

## 2. Why is SDLC important?
SDLC helps developers create quality software in an organized way. It reduces errors, saves time, and ensures the project meets user requirements.

## 3. List the seven phases of SDLC.
1. Planning
2. Requirements Analysis
3. Design
4. Development (Coding)
5. Testing
6. Deployment
7. Maintenance

## 4. Differentiate between functional and non-functional requirements.

### Functional Requirements
These describe what the system should do.
Example: Users can create an account and log in.

### Non-Functional Requirements
These describe how the system should perform.
Example: The website should load within 3 seconds.

## 5. What happens during the testing phase?
During the testing phase, the software is checked for bugs, errors, and performance issues to ensure it works correctly before release.

## 6. Explain the difference between deployment and maintenance.

### Deployment
Deployment is the process of releasing the software to users.

### Maintenance
Maintenance involves fixing bugs, updating features, and improving the software after it has been released.

## 7. Compare the Waterfall and Agile models.

### Waterfall Model
- Follows a fixed sequence of phases.
- Changes are difficult to make once development starts.
- Best for projects with clear requirements.

### Agile Model
- Uses an iterative and flexible approach.
- Changes can be made throughout development.
- Best for projects with changing requirements.

## 8. Who are the major stakeholders involved in SDLC?
The major stakeholders include:
- Clients or Customers
- Project Managers
- Business Analysts
- Software Developers
- Testers/QA Engineers
- End Users

## 9. What is User Acceptance Testing (UAT)?
User Acceptance Testing (UAT) is the final testing stage where end users test the software to confirm it meets their needs and requirements.

## 10. Why is maintenance important after deployment?
Maintenance is important because it helps fix bugs, improve performance, add new features, and keep the software secure and up to date.
